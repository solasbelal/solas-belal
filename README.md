## Local Development

The project can be edited directly using tools such as **Acode** on Android.

For root-level files such as `index.html`, asset paths use:

    <link rel="stylesheet" href="assets/css/main.css">

For pages inside folders such as `about/index.html`, asset paths use:

    <link rel="stylesheet" href="../assets/css/main.css">

JavaScript from the root page:

    <script src="assets/js/navigation.js" defer></script>
    <script src="assets/js/main.js" defer></script>

JavaScript from subfolder pages:

    <script src="../assets/js/navigation.js" defer></script>
    <script src="../assets/js/main.js" defer></script>

This relative path strategy helps the project work during local development and after deployment to GitHub Pages.

## GitHub Pages Deployment

### Deployment Steps

1. Push all project files to the `solas-belal` repository.
2. Open the repository on GitHub.
3. Go to **Settings**.
4. Open **Pages**.
5. Under **Build and deployment**, choose:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
6. Save the configuration.
7. Wait for GitHub Pages deployment to complete.

The production website should then be available at:

    https://solasbelal.github.io/solas-belal/
